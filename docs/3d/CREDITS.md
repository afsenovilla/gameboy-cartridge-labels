# 3D cartridge models

The meshes in `cart-models.js` are converted copies of models made by other people.
They are not covered by the licence of the rest of this repository.

| Cartridge | Model | Author | Licence | Changes |
| --- | --- | --- | --- | --- |
| Game Boy | [Game Boy Cartridge Shell - Type A](https://www.thingiverse.com/thing:3810798) | esotericsean | [CC BY](https://creativecommons.org/licenses/by/4.0/) | Front and back halves assembled, re-centred, repacked. |
| Game Boy Color | [Gameboy Color Cartridge shell](https://www.thingiverse.com/thing:5170188) | leslieslaw | [CC BY-NC-SA](https://creativecommons.org/licenses/by-nc-sa/4.0/) | Re-centred, repacked. This converted mesh is shared under the same licence: non-commercial use only. |
| Game Boy Advance | Solid cartridge model (`Gba.stl`) | Unknown | **Not confirmed** | Keyring hole filled, mesh simplified from about 309,000 to 36,000 triangles. |

The Game Boy Advance model came without author or licence information. Replace it, or add the
right credit here, before relying on it publicly.

The Game Boy and Game Boy Advance models carry the console maker's logo as part of the original files.
